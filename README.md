# Manacost Dev

Создаём сервисы для Hearthstone, Telegram-ботов и инструменты для работы с контентом.

[Сайт](https://hs-manacost.ru) · [Сообщество](https://vk.com/manacost) · [Поддержать](https://boosty.to/kolodahearthstone)

## Проекты

| Проект | Что делает |
| :--- | :--- |
| [HeartPulse](https://github.com/Manacost-Labs/HeartPulse) | Аналитика Hearthstone: мета, колоды и гайды. |
| [DeckView](https://github.com/Manacost-Labs/Deckview-TG) | Telegram-бот и API для визуализации колод. |
| [WordPress Skills](https://github.com/Zulut30/Wordpress-skills) | Навык для AI-агентов: разработка и проверка WordPress-плагинов. |
| [AI News Aggregator](https://github.com/Zulut30/newslatter-bot) | Сбор, фильтрация и публикация новостей об ИИ в Telegram. |

**Стек:** Python · TypeScript · JavaScript · PHP · WordPress
